# Cybersecurity Labs

Welcome to my **Cybersecurity Labs** repository! 

This repository serves as a centralized collection of my notes, write-ups, theoretical concepts, and practical lab environments as I continue to expand my knowledge in the field of cybersecurity. It is intended to document my learning progression, especially my journey actively completing tasks and hacking boxes on platforms like TryHackMe and hands-on vulnerable VM labs like Metasploitable 2.

## Repository Structure

The repository is modularized into different platforms or subjects I am practicing.

### TryHackMe (`/tryhackme`)

The `tryhackme` folder is organized exactly according to the categories and rooms taught on the platform. It contains markdown notes detailing the lessons learned, technical command sequences, tools used, and the answers to the questions provided in the specific rooms I've completed.

```text
tryhackme/
├── README.md
├── completed_rooms.txt
├── fundamentals/
│   ├── intro-to-defensive-security.md
│   ├── intro-to-lan.md
│   ├── intro-to-networking.md
│   ├── intro-to-web-security.md
│   └── what-is-networking.md
├── linux/
│   └── linux-fundamentals-part1.md
├── networking/
│   └── nmap.md
└── offensive-security/
    ├── basic-pentesting.md
    ├── intro-to-offensive-security.md
    ├── pickle-rick.md
    └── rootme.md
```

### Metasploitable 2 (`/metasploitable2`)

The `metasploitable2` folder contains hands-on exploitation notes and walkthroughs targeting the intentionally vulnerable Metasploitable 2 VM. Each file documents a specific service, vulnerability, or attack technique.

```text
metasploitable2/
├── README.md
└── telnet-exploitation.md
```
